# Agent issue authoring helper

This repository distributes teaching material and the agent-issue-authoring skill.
For a user's project issue, use `.claude/skills/agent-issue-authoring/SKILL.md` and
work in the user's actual project. Do not create their solution in this checkout.
The skill's `references/guide.md` is the source for the first part of README.md
and the one-page handout. Rebuild the README with `scripts/build_readme.py`.
Keep this helper's published source free of classroom transcripts, recordings,
student identifiers, credentials, and actual personal exercise records.
